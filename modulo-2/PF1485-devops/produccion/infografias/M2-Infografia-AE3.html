EXPLICAR LOS PRINCIPIOS DEVOPS, ROLES, RESPONSABILIDADES Y HABILIDADES, Y LAS CARACTERÍSTICAS PRINCIPALES DE SU CICLO DE VIDA PARA EL DESARROLLO DE PRODUCTOS DIGITALES.

1

Ciclo de vida DevOps

CONTENIDO

CICLO DE VIDA DEVOPS: DESARROLLO · PRUEBA · INTEGRACIÓN · DESPLIEGUE · MONITOREO

Desarrollo → prueba → integración → despliegue → monitoreo. Es un ciclo sin fin: lo que se aprende al monitorear vuelve al desarrollo.

2

Automatización

CONTENIDO

PRÁCTICAS ESENCIALES DE DEVOPS: AUTOMATIZACIÓN

Se automatiza lo repetitivo: compilar, probar, desplegar y crear servidores. Menos errores manuales y más tiempo para mejorar.

3

Integración continua

CONTENIDO

INTEGRACIÓN CONTINUA

Cada cambio se integra al repositorio principal varias veces al día y se compila y prueba solo. Si algo falla, el equipo se entera en minutos.

4

Entrega continua

CONTENIDO

ENTREGA CONTINUA

Cada versión que pasa las pruebas queda lista para producción y se publica con un clic. Si también ese paso es automático, se llama despliegue continuo.

5

Infraestructura como código

CONTENIDO

INFRAESTRUCTURA COMO CÓDIGO

Servidores, redes y permisos se describen en archivos versionados, con herramientas como Terraform o Ansible: se revisan, se repiten y se recrean igual cada vez.

6

Control de versiones y pruebas automáticas

CONTENIDO

HERRAMIENTAS DEVOPS: CONTROL DE VERSIONES · AUTOMATIZACIÓN DE PRUEBAS

Git guarda la historia del código y permite ramas y revisiones. Las pruebas unitarias, de integración y de punta a punta corren solas en el pipeline.

7

Monitorización y registro

CONTENIDO

MONITORIZACIÓN Y REGISTRO

Métricas, registros (logs) y alertas muestran cómo está el servicio en todo momento, con herramientas como Prometheus y Grafana.

8

Contenedores y orquestación

CONTENIDO

CONTENEDORES Y ORQUESTACIÓN

Docker empaqueta la aplicación con todo lo que necesita, para que funcione igual en cualquier lugar. Kubernetes despliega, escala y reinicia esos contenedores.

9

Roles y responsabilidades

CONTENIDO

ROLES, RESPONSABILIDADES Y HABILIDADES: ROLES QUE PARTICIPAN DENTRO DE DEVOPS · RESPONSABILIDAD DE CADA PERFIL

Developers: código y pruebas · Operaciones o SRE: confiabilidad · QA: calidad automatizada · Seguridad · Product Owner: valor del producto · Ingeniería DevOps: pipelines y automatización.

10

Habilidades de un especialista DevOps

CONTENIDO

HABILIDADES DE UN ESPECIALISTA DEVOPS

Técnicas: Linux, scripting, Git, integración y entrega continuas, nube y contenedores. Blandas: comunicación, colaboración y aprendizaje continuo.
