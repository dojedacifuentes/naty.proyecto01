**Criterios de evaluación (textuales del plan):**

- 2.1 UTILIZA LA INTERFAZ VISUAL DE N8N PARA CREAR WORKFLOWS BÁSICOS.
- 2.2 CONFIGURA TRIGGERS, NODOS DE PROCESAMIENTO Y ACCIONES DE SALIDA.
- 2.3 IMPLEMENTA WORKFLOWS FUNCIONALES CON AL MENOS TRES NODOS CONECTADOS.
