# entregables/

Lo que se le entrega a Natalia, **un directorio por hito**, con fecha:

```
entregables/<AAAA-MM-DD>-<tema>/
```

Cada directorio lleva un `README.md` que dice qué es cada archivo, quién lo hizo, de
dónde salió y si tiene una versión viva fuera del repo (un artifact, un documento
compartido). Lo que se entrega se versiona acá aunque también se haya mandado por otra
vía: el repo es la única fuente para reconstruir qué se entregó y cuándo.

| Hito | Qué contiene |
| --- | --- |
| [`2026-09-24-modulo2/`](2026-09-24-modulo2/) | Análisis de lo que exige el módulo 2, brainstorm ejecutivo, panel de entregables, manual de entregables y kits de recursos educativos del módulo 2 de PF1821 y PF1822 |
| [`2026-09-30-exigencias-modulo2/`](2026-09-30-exigencias-modulo2/) | Qué exige 2026 del módulo 2 de los 15 cursos: planilla Excel y PDF con verbo, objeto y condición de cada aprendizaje y criterio, cantidades para el 7,0 y cambios desde 2024 |
| [`2026-09-30-texto-canonico-modulo2/`](2026-09-30-texto-canonico-modulo2/) | Texto oficial del módulo 2 de PF1821 y PF1822, verificado contra el PDF de SIPFOR, para cotejar y corregir los cursos de Rise 360: planilla con comparación automática y página con botones de copiar |

Los PDF de las bases no van acá sino en [`bases/`](../bases/): son la fuente, no un entregable.
